================================================================================
                          UTILISATION
================================================================================

POUR LES ENSEIGNANTS:
  1. Accéder à http://localhost:8000/gamification/
  2. Cliquer sur "Espace Enseignant"
  3. Créer une room
  4. Générer un quiz avec IA
  5. Partager le code avec les étudiants

POUR LES ÉTUDIANTS:
  1. Accéder à http://localhost:8000/gamification/
  2. Cliquer sur "Rejoindre une Room"
  3. Entrer le code de la room
  4. Passer le quiz
  5. Voir les résultats et badges
